# Cebu Family Guide｜親子で迷わない現地ガイド

セブ親子短期滞在について、出発前に一度読んでおける「準備ガイド」と、現地で「これどうしよう」と迷ったときにそのまま使える「クイックリファレンス」を、1枚のページの中で両立させたガイドです。

デザイン・UIは、以前Claude Codeで制作したボラカイ島の `parent-guide.html`（同行者向け準備ガイド）を完成見本として、同じ構成・同じCSS設計トークン（配色・余白・角丸・影）・同じアコーディオン構造で作成しています。ボラカイ版と並べても同じシリーズのページに見えることを基準にしました。

---

```
cebu-family-guide/
├── index.html   … ページ本体（すべてのテキスト・構成はここに記載。単一ページ構成）
├── style.css    … 見た目（色・レイアウト・印刷用スタイル）
├── script.js    … ハンバーガーメニュー・アコーディオン開閉・TOPへ戻るボタン

```

フォントは Google Fonts の Noto Sans JP のみ（ボラカイ版と共通）。アイコンや絵文字には頼らず、太さ違いと配色で情報の重みを表現しています。

### 「13. 子どもの体調不良・病院」章の内部構成

旧「13. 子どもの体調不良」と旧「14. 病院・医療」を1章に統合しています（`id="health"`。旧`id="hospital"`は廃止）。内部は以下の流れで整理しています。

1. 子どもが体調不良になったとき（`.lead-statement`：まず予定を中止して休ませる）
2. その後の流れ（`.journey-steps` 3ステップ：保険連絡先確認／Japanese Help Desk等へ相談／必要に応じて受診）
3. 病院に行くか迷ったとき（`.caution-box`：保険会社またはJapanese Help Desk等へ相談）
4. 病院候補（`.area-grid` Cebu Doctors／Chong Hua ＋ `.note-box` で「推奨」「安全」と表現しない旨を明記）
5. 現地で迷ったら（`.quick-decide` 3項目：体調不良／病院に行くか迷う／受診が必要になった）

医療運用の内容（保険連絡→Help Desk→受診の順序、病院候補2件、911／161）は変更せず、章構成のみ統合しています。

### 3-1. 「9. 通信・スマートフォン」章の内部構成（ボラカイ版と同程度に詳細化）

他の章より情報量が多いため、内部構成のみここに整理します（上から順）。

導入文 → 通信手段を選ぶ（4択の紹介）→ eSIM（確認事項6項目）→ 現地SIM・eSIM（確認事項6項目）→ Globe／Smartカード（`.carrier-grid`、簡潔な表示のみ）→ SIM登録の注意（`.note-box`）→ 日本のスマホをそのまま使う場合（変動要素の`.bullet-list`＋日本の携帯会社11社への`.link-list`）→ ホテルWi-Fi → 地図も事前に準備 → Grab利用に備えて（通信・バッテリーの確認のみ4項目。判断ルール本体は「4. 移動・夜」を参照）→ モバイルバッテリー → 緊急連絡先は紙でも → 出発前に確認しておきたいこと（`.check-list` 10項目）→ 現地で迷ったら（`.quick-decide` 8項目）→ 章末の強調枠（`.caution-box`、「通信について」）。

### Grab情報の役割分担（「4. 移動・夜」と「9. 通信・スマートフォン」）

Grabに関する説明は、以下のように章の役割で分けており、同じ内容を両章で重複記載していません。

- **「4. 移動・夜」**：Grabをいつ使うか・どう判断するか・乗車時に何を確認するか（`.check-list`「Grabを使うとき」7項目、`.quick-decide` 7項目）

Grab関連の記述を追加・修正する場合は、判断ルール自体は「4. 移動・夜」に、通信・バッテリーの準備事項は「9. 通信・スマートフォン」に追加してください。

## 3. 各章の型

ボラカイ版と同じ情報構造（①章タイトル→②導入文→③事前に知っておくこと→④具体的な場面→⑤持参・準備するもの→⑥現地での判断→⑦強調枠）を基本形にしています。

```html
<div class="accordion" id="◯◯">
  <button class="accordion-header open" aria-expanded="true">
    <div class="accordion-header-left">
      <div>
        <div class="accordion-title">2. 水・飲み物</div>       <!-- ① 章タイトル -->
        <div class="accordion-subtitle">飲み物選びの基本</div>  <!-- ② サブタイトル -->
      </div>
    </div>
    <span class="accordion-arrow">▼</span>
  </button>
  <div class="accordion-body open">
    <p>短い導入文。</p>                                        <!-- ③ 導入文 -->
    <div class="section-photo"><img src="..." alt="..." loading="lazy"></div>

    <p class="section-subhead">まず覚えておきたいこと</p>        <!-- ④ 事前に知っておくこと（矢印付き箇条書き） -->
    <ul class="check-list">
      <li>基本ルールの説明</li>
    </ul>

    <p class="section-subhead">（任意）具体的な場面の見出し</p>  <!-- 内容が2グループに分かれる章のみ（例：水は「まず覚えておきたいこと」＋「飲み物を選ぶとき」の2本立て） -->
    <ul class="check-list">
      <li>場面ごとの説明と、そのときの行動</li>
    </ul>

    <p class="section-subhead">（任意）持っていきたいもの</p>     <!-- ⑤ 小カード・チップ（持参・準備するものがある章のみ） -->
    <div class="pack-grid">
      <div class="pack-item">アイテム名</div>
    </div>

    <div class="caution-box">                                  <!-- ⑦ 淡い色の強調枠（章で最も重要な1点） -->
      <strong>迷ったら：</strong>短い結論。
    </div>

    <div class="quick-decide">                                 <!-- ⑥ セブ版独自：現地で迷ったら -->
      <p class="qd-label">現地で迷ったら</p>
      <div class="qd-item">
        <span class="qd-q">状況</span>
        <span class="qd-arrow">→</span>
        <span class="qd-a">行動</span>
      </div>
      <!-- 2つ目以降の .qd-item をここに続ける -->
    </div>
  </div>
</div>
```

**`.check-list` と `.quick-decide` の使い分け：** `.check-list`（③④）には、その章に関する確定済みの内容を**すべて**、文章として読める形で載せています。`.quick-decide`（⑥）は、そのうち現地でとっさに使う頻度が高いものだけを2〜4件に絞った早見表です。件数を絞っているのは省略ではなく、「現地で数秒で見つけられる」ことを優先した結果で、絞り込まれた項目も含めて確定済み内容はすべて `.check-list` 側に残しています。

写真（`.section-photo`）とチップ（`.pack-grid`）は章によって省略しています（写真は水・飲み物、食事、移動・夜、防犯、暑さ・雨・冷房、虫・動物、通信の7章のみ／チップは防犯、暑さ・雨・冷房の2章のみ）。体調不良・病院医療・緊急時の章は、ボラカイ版の医療系章にならい、チェックリストの代わりに `.journey-steps`（3ステップ）や `.area-grid`（病院候補カード）・`.emergency-card`（緊急連絡先）を使っています。チップ・生活情報の2章は、ボラカイ版の同種チャプターにならい、判断ボックス（`.quick-decide`／`.caution-box`）を持たない読み物形式のみにしています。支払い章のみ、Wise／Revolut追加時に `.quick-decide` を追加しています（詳細は後述）。

### 現地通信会社カード（`.carrier-grid` / `.carrier-card`）

「9. 通信・スマートフォン」章にのみ、Globe・Smart（フィリピンの現地通信会社）を横並びの2枚のカードで紹介しています。カード本文はあえて簡潔にしており（「旅行者向けSIM／eSIMあり」＋「公式サイトで確認」の2行のみ）、対応端末・登録要否等の詳細チェック項目は、カードの手前にある「現地SIM・eSIM」の `.check-list` 側にまとめています。

- 料金は固定表示せず、公式サイトで確認する前提の文章にしています
- 「どちらがおすすめ」等の比較・推奨は記載していません（優劣をつけない方針）
- 各カードには公式リンク（Traveler/Tourist SIM・eSIM、SIM Registration）のみを掲載しています
- SIM登録が必要である旨は、カードの下の `.note-box`（目立ちすぎない注意枠）にまとめて記載しています

追加のリンクを増やす場合も、`.carrier-links` 内に `<a>` を1行追加するだけです。料金・速度・電波状況など断定的な内容は追加しないでください。

### その他のコンポーネント（ボラカイ版と共通）

- `.info-box` / `.note-box` / `.caution-box`：色分けした補足・注意・強調ボックス
- `.check-list`：矢印（→）プレフィックスの箇条書き。章の「知っておきたいこと」に使用
- `.pack-grid` / `.pack-item`：横並びの小さなチップ・カード。「持っていきたいもの」等に使用
- `.link-list`：矢印プレフィックスのリンク一覧（`.check-list` と同じ見た目でリンク化したもの）。「通信」章の日本の携帯会社11社リンクに使用
- `.fine-print`：小さめの灰色注記テキスト。特定事業者を推奨しない旨・料金変更の可能性などの断り書きに使用
- `.label-confirm`：「要確認」バッジ（赤系ではなく琥珀色）
- `.bullet-list`：通常の箇条書き（`–` プレフィックス）。章1・2・支払い・チップに使用
- `.journey-steps` / `.journey-step`：番号つきステップ（体調不良の3ステップに使用）
- `.area-grid` / `.area-card`：病院候補などの小カード
- `.emergency-card`：濃紺の緊急連絡先カード（911／161）

### 支払い・チップ・生活情報の内容方針

これら3章は、出発前の時点でセブ版として確認済みの具体的な内容（社内マスター等）が現状ないため、以下の方針で作成しています。

- フィリピンペソ（PHP）、フィリピンの一般的な電圧など、**客観的な国情報として断定できる事実のみ**明記
- クレジットカードの実用可否、ATM手数料・場所、洗濯店舗・料金など、**判断・推奨を伴う具体的内容は「要確認」**として明示し、断定していません（`.note-box` に `.label-confirm` を使用）
- チップは金額・割合を一切固定表示せず、「必須ではない」「service chargeの有無を確認する」という考え方のみ記載しています
- 社内マスターに具体的な確認済み情報（店舗名・料金・手数料等）が追加された場合は、該当する `.note-box` の文言を差し替え、事実部分は `.bullet-list` に追記してください

### 「10. 支払い」章の内部構成

以下の順に `.section-subhead` で整理しています（通貨情報は「12. 生活情報」から本章へ移動済み）。

1. 支払い手段の基本（導入文）
2. 通貨（フィリピンペソ／PHP）
3. 現金
4. クレジットカード／デビットカード
5. Wise
6. Revolut
7. ATMに関する注意（`.note-box` ＋ `.label-confirm`）
8. 現地で迷ったら（`.quick-decide`）

### 支払い手段としてのWise／Revolut（「10. 支払い」章）

現金・通常のクレジットカード／デビットカードに加えて、複数の支払い手段のひとつとしてWiseとRevolutを紹介しています（「おすすめランキング」ではなく選択肢の案内という位置づけ）。

- 各サービスとも、`.section-subhead` の下に説明文＋確認事項の `.check-list`（カード有効化／PIN／アプリ残高／ATM手数料表示／各社の最新条件）＋`.carrier-links` で公式リンクのみを掲載
- 無料出金回数・手数料・為替レートなど、変更されうる具体的な数値は一切記載していません（`.fine-print` で明記）
- 両サービスの比較・優劣・「必ず使える」という断定は行っていません（`.fine-print` で明示的に否定）
- 章末の `.quick-decide` に、支払い手段に迷ったときの4項目（カードだけで大丈夫か／Wise・Revolut利用前の確認／ATM手数料確認／カード決済不可時の切り替え）を追加しています（他の2社と異なり、この章のみ判断ボックスを持つ構成に変更しました）

## 4. テキストを直す・差し替える方法

1. `index.html` を開き、直したい文言をそのまま書き換えてください（HTMLタグは残したまま、タグの中の日本語だけを変更すればOKです）。
2. 「現地で迷ったら」に項目を追加したい場合は、同じ `.quick-decide` 内にある `.qd-item` ブロックをコピーし、文言だけ差し替えてください。
3. 項目を削除したい場合は、該当する `.qd-item` ブロックごと削除してください。

### 表現ルール（変更時も維持してください）
- 「安全／危険」の二択表現にしない（例：「これは安全です」「20時以降は危険です」は使わない）
- 断定的な推奨表現を避ける（例：「有名店だから安全」「推奨病院」は使わない）
- 不明な内容は「未確認」「要再確認」と明記する
- 「避ける」「注意する」だけで終わらせず、可能な限り「次に何をするか」を明示する

### 表示していないが削除していない項目

`#emergency` 章（15. 緊急時）の緊急連絡先カード内に、「保護者が動けない場合」（子どもの監護フローが要再確認の項目）についてのHTMLコメントを残しています。運用フローが確定していない項目を「今どうする？」のガイドに出すと、答えのないカードになってしまうためです。削除したわけではないので、社内で運用フローが確定した時点で、コメント内の指示に従って追加してください。

## 5. 章を追加・削除する場合

1. `index.html` 内で `<div class="accordion" id="◯◯">…</div>` を1ブロックとして扱ってください。
2. 追加した場合は、`#siteNav`（ハンバーガーメニュー）内の `<li><a href="#◯◯">…</a></li>` にも追加してください（漏れるとメニューから開けません）。番号（1〜16、参考情報・出典は17）がずれる場合は `.accordion-title` の数字と `.site-nav` 側の数字を両方揃えてください。

## 6. デザイン・色を調整する場合

`style.css` 冒頭の `:root { … }` 内にある変数を変更すると、ページ全体の配色が一括で変わります（ボラカイ版と同じ変数名・同じ値を使用しています）。

- `--ocean` 系：メインのアクセントカラー（リンク・アイコン・「現地で迷ったら」枠）
- `--sand` / `--ivory` 系：背景のニュートラルカラー
- `--navy`：見出し・ヘッダー背景・緊急連絡先カードの背景・ページヒーローのグラデーション
- `--sunset` 系：「困ったとき」フローティングボタン用の暖色。警告色ではなく「重要なので目立たせる」用途のみに使用
- `--amber` 系：「要確認」バッジ用の落ち着いた琥珀色（赤系は使っていません）

トイレ／支払い／生活情報／子どもの体調不良・病院の4章は、これまで章内に写真がありませんでした。今回のご指示に沿って、他章と同じ `.section-photo` の配置パターン（導入文またはリード文の直後）で新規に写真を追加しています。

`images/` 内のファイルは1点あたり2〜2.6MB程度のPNGです。公開前にJPEG変換・圧縮（例：1200px幅程度にリサイズし、品質80%前後で書き出す）を行うと、スマートフォンでの読み込みが速くなります。

自社で撮影・生成した写真にさらに差し替える場合は、`images/` フォルダ内の該当ファイルを同じファイル名で置き換えるか、`<img>` タグの `src` を新しいパスに書き換えてください。

いずれも「単体の商品写真」「モデル写真感の強い人物ポートレート」を避け、旅行の場面が伝わる構図に寄せています。人物が写る写真は、顔が判別しにくい構図（後ろ姿・肩車・手元）を優先し、金髪の欧米人モデルが主役になるような広告写真的な人物構成は避けています。「4. 移動・夜」「9. 通信・スマートフォン」の2章は今回のご指示により変更していません。

自社で撮影した写真に差し替える場合は、該当する `<img>` タグの `src` を自社サーバー上の画像パス（例：`images/water.jpg`）に書き換えるだけで反映されます。

## 8. PDF化・印刷時の注意

- 印刷用スタイルは `style.css` 末尾の `@media print { … }` に定義済みです。ヘッダー・章一覧メニュー・フローティングボタンは印刷時に自動的に非表示になり、すべてのアコーディオンは強制的に展開されて印刷されます。
- 緊急連絡先カードは、印刷時のみ濃紺背景を解除し、白背景に読み替えます（インク節約・視認性のため）。
- 用紙はA4縦、余白14mm/12mmで設定済みです（`@page` ルール）。ブラウザの「印刷」→「PDFとして保存」でそのままPDF化できます。

## 9. 「参考情報・出典」を更新する方法

`index.html` の `id="sources"` セクションには、社内マスターで確定済みの主要な出典8件を2つのグループ（公的情報・公式情報／海外旅行保険・医療関連）に分けて掲載しています。「現地確認」「当社運用」の2件は、社内向けの区分であり出典として掲載する必要がないとの判断で削除済みです。

```html
<div class="source-group">
  <p class="source-group-label">公的情報・公式情報</p>
  <div class="source-item">
    <span class="source-name">表示名（社内マスターどおり）</span>
    <p class="source-desc">短い説明（社内マスターどおり）</p>
    <a class="source-link" href="URL" target="_blank" rel="noopener noreferrer">URL</a>
  </div>
</div>
```

- URLのない出典（「現地確認」「当社運用」）は `.source-link` を付けず、名前と説明のみ表示しています。無理にリンク化しないでください。
- 表示名・説明・URLは社内マスターの記載をそのまま転記してください。新しい出典の追加や、未確認の出典の推測補完、URLの検索・差し替えはしないでください。
- 区分（グループ）を追加する場合も、公的情報・公式情報／現地確認／当社運用ルールを混同しないよう、新しい `.source-group` として分けてください。
